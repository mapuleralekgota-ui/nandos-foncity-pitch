# Nando's x FonCity Pitch

Static long-page pitch for the Nando's x FonCity partnership deck.

## Deploy On Vercel

Use this `deploy` folder as the site root.

Recommended Vercel settings:

- Framework Preset: Other
- Build Command: leave empty
- Output Directory: leave empty
- Install Command: leave empty

The site entry point is `index.html`.

## Files

- `index.html` - scroll-based pitch experience
- `preview/` - rendered slide images used by the page
- `vercel.json` - static cache headers for Vercel
